# Clear Browser 🦈

**Un navegador ligero para Windows, con una interfaz inspirada en el océano.**

Clear Browser es un proyecto de navegador de escritorio desarrollado con Electron, enfocado en ofrecer una experiencia sencilla y personalizable.

## Características

- Interfaz inspirada en el océano.
- Logotipo de tiburón ballena.
- Configuración y opciones de personalización.
- Sistema de actualizaciones automáticas para Windows x64.
- Verificación criptográfica de los manifiestos de actualización mediante Ed25519.
- Verificación de integridad de los instaladores mediante SHA-512.

## Instalación

Descargá el instalador de Windows desde la sección [Releases](https://github.com/Ruzinks/clear-browser/releases).

## Actualizaciones

Las actualizaciones automáticas dependen de que haya una versión estable publicada y de que el canal de actualización esté correctamente configurado.
